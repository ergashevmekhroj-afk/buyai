# Real seller prices (mentor feedback S3: "0 real sellers")

Goal before 18:00: 5-10 **real** prices from real sellers, posted through the app's **Sotuvchiman** tab
(https://buy-smarter.vercel.app/#seller), so they show with the **Jonli / Live** badge, not Demo.

## How (30-60 min, 2 people)
1. Go to the nearest bazaar (or phone sellers you know). Ask for today's price of the demo-order products first:
   **guruch (rice), kungaboqar yog'i (oil), piyoz, sabzi, mol go'shti, shakar, un, tuxum.**
2. Ask the seller: "Can we put your price and phone number on our app?" **Only write the phone if they say yes**
   (personal data law). No consent → write the stall name only, leave phone empty.
3. Fill one row per product in `template.csv` (on paper is fine, copy later).
4. Post each row in the Sotuvchiman tab from a phone. Check it appears under Bozor with the Live badge.
5. Run the demo order once: if a real offer is cheapest, the plan picks it.

## Rules
- Write the price exactly as the seller said it (so'm per kg / litre / 10 eggs). No rounding, no guessing.
- If a seller won't give a price, skip them. Never post a made-up "real" price.
- Keep the filled `template.csv` as evidence (date, time, who collected it).

Pitch line: "Our first N real sellers are from <bazaar>, collected on 18 Nov; their offers show as Live."
